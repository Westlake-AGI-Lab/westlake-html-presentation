# Private Research Data

Only this README is tracked. All other contents of this directory are ignored.
Store permitted lecture sources, consented and de-identified responses, annotation files,
and validated JSONL dataset builds here. Never force-add data to Git.

The application does not automatically export private chats here. Consent for research,
teacher summaries, local saving and public dataset release are separate decisions.
Document the applicable ethics approval/exemption before collecting human research data.
The CLI validates declarations; it cannot verify consent or remove identifying text.

See `experiments/assessment_agreement/README.md` for the current JSONL schema.
