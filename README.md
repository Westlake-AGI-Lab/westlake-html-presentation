## 大学 Private Token 接入（2026-11-01）

课程工作区需要本地账号，直接讲义资源沿用原访问策略。小西默认使用每位学生自己的大学 Private Token。打开小西，在“连接你的大学 AI 账号”面板选择已文档化的模型并连接。面板链接 https://hpc.westlake.edu.cn/#/ai-campus：请在大学页面使用校园账号登录，打开 **Model Service / API**，申请 Private Token，仅将该令牌粘贴到小西。SlideMate 不收集校园用户名或密码。只有真实推理成功并完整返回文字后才显示“已连接”。连接不会自动发送草稿，请自行点击发送。展开连接状态，点击“断开连接并删除令牌”即失效。连接或问答失败会保留问题草稿。

提供商依据：[大学 HPC 手册](https://hpc.westlake.edu.cn/document/science/soft/more/ai.html) 明确给出校园网 OpenAI 兼容地址 `https://hpc-api.westlake.edu.cn/v1`，及区分大小写的 `deepseek-flash`、`glm-flash`、`Qwen`。后端使用固定完整端点 `https://hpc-api.westlake.edu.cn/v1/chat/completions`、`Authorization: Bearer <Private Token>`，JSON 字段为 `model`、`messages`（system/user/assistant 文字）、`stream: false`。不依赖 OpenAI 托管服务或 SDK，不假定支持 Responses、工具调用，也不盲目追加 `/v1`。不提供已下线别名。无凭据访问文档端点返回 HTTP 401，确认可达与鉴权门槛，**不代表**真实令牌或模型兼容性已验证。未收到获授权的真实测试凭据，真实文字推理仍待验证，未使用维护者凭据调用或计费。

小西发送当前页文字/讲稿、问题与所选最近对话（最多 12 条、历史文字最多 20,000 字符），不会发送整门课程。浏览器问答请求省略其他页正文，后端也独立限制上游上下文为当前页。历史对话可能提及前页。文字上下文不代表图像理解。大学资料虽宣传图像能力，但实际图片请求兼容性未验证，大学模式已禁用上传、框选/图片请求及视觉苏格拉底式练习，后端同样拦截。生成讲解页使用学生会话且仅提供当前页文字。大学接口诚实采用完整非流式响应；独立维护者模式保留原 SSE。错误分别说明令牌无效/过期、模型未授权/不可用、额度/频率、校园网/VPN 故障、超时、响应中断/不兼容，不自动重试。

令牌只通过同源 POST 和固定大学端点传递，仅存服务器进程内存，以随机 256 位会话标识隔离学生。Cookie 为 HttpOnly、SameSite=Strict，路径 `/api/`。不会向浏览器返回令牌，也不写入浏览器存储、数据库、配置、档案、导出或日志。服务商错误不透传响应正文，成功回答若原样回显凭据也会脱敏。断开、过期、重启均使连接失效。默认绝对寿命 **7,200 秒（2 小时）**，问答不续期；访问时及每 60 秒清除过期记录。停止/断开后已发出的上游请求可能运行至超时，但不能再用已失效会话发起新请求。每学生同时一个请求，默认每小时 30 次，叠加原有服务器额度；连接尝试使用原 IP/全局限制。最多 1,000 会话，连接体 8 KiB，问答体 12 MiB，上游响应 2 MiB，套接字超时 45 秒并限制读取。不跟随重定向，尤其不跨主机转发凭据。保留原 Host/网络限制和仅本机默认值。

配置仅由服务器维护者控制，修改后重启：`UNIVERSITY_MODELS` 为三个文档别名的子集，`UNIVERSITY_SESSION_SECONDS` 范围 300–43,200，`UNIVERSITY_REQUESTS_PER_HOUR` 范围 1–200。浏览器不能提交上游地址，也没有存放学生令牌的配置文件。默认 `PPT_AI_MODE=university`，绝不回退到 `OPENAI_API_KEY`；保留维护者原密钥和模型配置。明确设置 `PPT_AI_MODE=operator` 可兼容先前独立讲稿 Responses 流程；课程目录演示即使设置此项仍强制大学模式。不得用 operator 模式服务学生课程。教师管理继续使用独立维护者集成。

远程输入 Private Token 必须使用 HTTPS。普通内网 HTTP（包括 `http://10.21.3.45:8765/`）禁止接收令牌，本机回环 HTTP 可继续开发。**本次未安装 HTTPS 反向代理**。只有完成单独安全设计后才可配置 `UNIVERSITY_PUBLIC_ORIGIN=https://slides.example.edu`：受信代理终止 TLS、保留精确 Host、通过回环地址连接后端，且阻止远端直接访问 Python 监听端口。后端不信任任意转发协议头，为已配置 HTTPS 设置 Secure Cookie。保留回环监听；更改绑定地址不等于公网部署。校园网/VPN 需在 SlideMate 服务器上可用，仅学生浏览器联网不够。

验证：`PYTHONPATH=src PPT_AI_MODE=operator python3 -m unittest discover -s tests -p 'test_*.py'` 验证旧模式及新测试（新 HTTP 测试明确强制大学模式）。覆盖两个并发学生、缺失/过期/断开会话、无共享密钥回退、Bearer/别名/请求格式、脱敏、当前页、额度/并发、服务商错误、图片拒绝和安全 Cookie。实际 8784 演示通过明确模拟的大学传输进行浏览器检查，未用真实令牌：选课→讲义→连接失败且保留草稿→键盘显示/隐藏→连接且不自动发送→问题/响应→翻第 2 页追问无需重连→断开；检查 390px 手机布局。真实文字与图像推理分别仍未验证，图片功能继续禁用。内网同步待完成：SSH 鉴权被拒绝；HTTP 返回 200，但未修改远端文件、配置或服务，不宣称已部署。独立 Diffusion 讲稿保持原样。

## SlideMate 视觉苏格拉底式练习

以下为旧维护者模式流程；大学模式在图片接口单独验证前禁用这些依赖图片的操作。

使用现有讲义 **Practice**，再点击 **开始本页视觉练习**。开始操作会将所选幻灯片图像及文字发送至已配置的服务端模型服务商。不新增登录、课程、示例讲稿或替代仪表盘。PDF 练习通过本地目录解析课程/讲义/页码，使用已登记的教师原图，替换客户端提供的像素与文字。HTML 练习捕获浏览器当前渲染页面；它是浏览器快照，不是经核验的教师原稿。个人 PDF 标注与高亮不属于原图。媒体、复杂 CSS 和动画状态可能无法准确捕获，请核对快照。

独立的 Curator 和 Questioner 调用识别可见元素、归一化边界框及空间/拓扑关系，然后生成引用这些元素的 Apply/Analyze/Evaluate/Create 问题。私有评分标准与完整推理保留在服务端。页码、幻灯片标识、文字和图像绑定至 SHA-256 快照版本。缺少视觉引用、坐标无效或视觉不可靠时会拒绝生成，而不是静默退回纯文本问题。标记区域由 AI 生成，仍需核对；坐标/结构检查不能证明视觉解读正确。

每次实质性作答依次调用 Assessor、Socratic Tutor 和独立模型 Critic。评估需引用学生原文及问题涉及的视觉元素。误概念得到针对性的反问或反例，不返回预设提示或直接纠正。Critic 在展示前检查问题的视觉依据及答案泄露。模型检查仍可能出错，不保证绝对不泄露，也不声称优于其他产品。本次未进行真实模型质量评估。

至少两次不同的有效作答、一次导师追问且最近修订得到支持后，才解锁 **对照完整推理**。首次正确回答仍会收到追问。空白/过短/重复回答、模型判定的未实际作答、过期版本及提前请求解析都不能推进服务端门槛。投入阈值与模型评估无法证明真实人类推理。在练习会话进行中，普通助手发送及 Create slides 操作会返回对话，直到已打开完整推理。此界面门槛不是身份认证或考试访问控制。失败请求保留输入草稿，不记录评分后的尝试。切换页面或修改文字需开始新会话；后续操作前服务端也会检查已登记 PDF 是否变化；页面未关闭时仍显示旧对话。
